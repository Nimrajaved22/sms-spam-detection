# sms-spam-detection
Machine Learning project for classifying SMS messages as Spam or Ham using Python and Scikit-learn.
# SMS Spam Detection

## Project Overview

This project uses Machine Learning to classify SMS messages into two categories:

* **Ham** – Normal/legitimate messages
* **Spam** – Unwanted or promotional messages

The project was developed using Google Colab and Python.

## Objective

The main objective of this project is to build a Machine Learning model that can automatically identify whether a given SMS message is Spam or Ham.

## Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* TF-IDF Vectorizer
* Machine Learning Classification

## Project Workflow

1. Load the SMS dataset
2. Explore the dataset
3. Clean and preprocess the text
4. Convert text into numerical features using TF-IDF
5. Split the data into training and testing sets
6. Train the Machine Learning model
7. Evaluate the model
8. Test the model with new SMS messages

## Dataset

The dataset contains SMS messages labeled as either **Ham** or **Spam**.

## Result

The trained Machine Learning model can classify new SMS messages as Spam or Ham based on patterns learned from the training data.

## How to Run

1. Open the `.ipynb` file in Google Colab.
2. Upload the dataset if required.
3. Run the notebook cells from top to bottom.
4. Check the model evaluation and prediction results.
